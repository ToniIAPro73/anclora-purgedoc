## Decisions

1. **Git policy.** Branches `development`, `staging`, `production`, `main` exist; `development`
   is the working and GitHub default branch. Feature branches are disallowed unless Toni orders them.
2. **Promotion.** `development → staging → production → main`, only through the manual
   `promote.yml` workflow: fast-forward only, no merge/rebase/cherry-pick/force push, and only
   for a source SHA with a successful `CI / Development` run. Agents never promote on their own.
3. **CI.** `ci.yml` runs real gates on `development`, `staging`, `production` (frontend install,
   tests, build; backend install, compile, full pytest suite including HTTP tests against a
   local uvicorn). `main-baseline.yml` re-verifies the published baseline on `main`.
   No `|| true` or equivalent masking is allowed.
4. **Secret protection.** `.env*` files are gitignored except `*.env.example`; local secret files
   use mode `0600`; values are never printed in logs, docs or reports.
5. **Document privacy.** User documents are never versioned or uploaded; tests and CI use only
   synthetic fixtures generated by `backend/fixtures_generator.py`.
6. **Operational independence.** Runtime, build and CI must not require any coding-agent vendor
   service. Emergent-hosted packages are excluded from the CI install (see below).
7. **Bootstrap scope.** No product behavior, API, algorithm, OCR, detection rule, encryption,
   audit or data model was changed by this bootstrap.

## Legacy Emergent artifacts

The following come from the Emergent build environment. They do NOT constitute runtime
authority and were intentionally not removed in this bootstrap:

- `.emergent/` (local, gitignored), `test_reports/`, `test_result.md`, agent notes in `memory/`.
- `backend/requirements.txt`: `emergentintegrations` (not on PyPI, Emergent private index) and
  `litellm` (pinned to an Emergent-hosted wheel). Neither is imported by the code; CI installs
  the manifest minus these two lines and `pip check` passes. Also unused by code: `motor`,
  `pymongo`, `boto3`, `stripe`, `openai`, `google-genai`, `google-generativeai`, `google-api-python-client` (note: `google-re2` IS used).
- `backend/.env.example`: `MONGO_URL`, `DB_NAME` (not read by the code).
- `frontend/package.json`: `@emergentbase/overlay`, `@emergentbase/visual-edits`
  (dev-server only, installed from `assets.emergent.sh`) wired in `frontend/craco.config.js`.
- Tests `backend/tests/test_api_e2e.py` and `test_encrypted_ruleset_http.py` default to a
  former Emergent preview URL; CI always overrides it with `REACT_APP_BACKEND_URL` pointing
  to a local backend.

Removing these is follow-up technical debt requiring an explicit mission.
